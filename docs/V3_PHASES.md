# TukTuk V3 — План фаз

Статус: **continuous (с фазы 4)**  
Правило (обновлено владельцем 2026-08-03): фазы **4–9** идут без пауз на «фаза N ок»; после каждой — APK + push. Единственный финальный стоп — **«V3 ок»** на фазе 10. Фазы 0–3 уже **ок**.

Связанные документы:

- `docs/V3_CONSTITUTION.md` — закон продукта
- `docs/V3_UX_BASELINE.md` — UX-решения
- `docs/ROUTER_VPS.md` — Router / VPS

Режим работы (утверждено):

- **Фаза 0 и документные срезы** — облако
- **Тяжёлый UI / APK-итерации** — локально (ставить APK и смотреть)
- После каждой кодовой фазы — **APK + ссылка на релиз**, если есть что ставить

---

## Как ведём фазу

1. Прочитать конституцию.
2. Обновить UX-baseline (если UI).
3. Реализовать только scope фазы.
4. Пройти DoD.
5. Коммит / merge в `master`.
6. Если UI: собрать APK, выложить релиз, прислать ссылку.
7. Фазы 4–9: сразу следующая. Фаза 10: спросить «V3 ок?»
