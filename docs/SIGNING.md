# Подпись APK (важно для обновлений)

Android разрешает «обновить поверх» **только** если SHA-256 сертификата совпадает.

## Текущий официальный ключ (с v0.3.2 / v0.1.4)

- Файл: `app/release.keystore` (gitignored)
- Alias: `tuktuk`
- SHA-256: `573c85663e25bf9afa379a076d4a194997bd99cbf6c94cc919c4b28e14c230c5`
- Бэкап паролей: `secrets/RELEASE_KEY_BACKUP.txt`

**Никогда не запускай** `FORCE=1 ./scripts/setup-official-signing.sh` — это создаст новый ключ и снова сломает обновления.

## Старые релизы (v0.2 … v0.3.1)

Были подписаны **другим** ключом с тем же CN (`TukTuk Official`), SHA-256:

`4dff9ec22c9aa2700c7909d51efda6c4d459f13673944aa62a081768adc4327a`

Этот keystore на машине **не найден** (скорее пересоздан скриптом). Поэтому с APK ≤0.3.1 нельзя обновиться на 0.3.2+ без удаления — один раз удалить старое и поставить новый APK. Дальше обновления с тем же `release.keystore` ставятся поверх.
