# Event Anchor PWA (фаза 3 — без native iOS)

Apple: «больше замков, чем дверей». TukTuk не гонит App Store — Android раздаёт локальный HTTP-якорь, iPhone заходит через Safari.

## Как работает

1. На Android: вкладка **Толпа** → создать офлайн-комнату → **Якорь Wi‑Fi для iPhone**.
2. Включите точку доступа / раздайте Wi‑Fi с этого телефона.
3. На iPhone: Safari → `http://192.168.43.1:8787` (или URL из тоста / подсказки на экране).
4. PWA показывает ленту комнаты и шлёт короткие тексты на якорь; Android прокидывает их в Crowd plane / feed.

Порт по умолчанию: **8787** (`EventAnchorServer`).

## Event kit для организатора

- QR на URL якоря (напечатать / экран у входа).
- QR на payload комнаты (`EventRoomStore.qrPayload`) для Android-клиентов без OTP.
- Режим **Толпа** на 4 часа (auto-exit) + опциональный auto-crowd при плотной рекламе.
- VPS / Oracle не обязательны для локальной комнаты; остаются для контактов и DTN-подсказок вне стадиона.

## Ограничения (честно)

- iPhone не крутит BLE-меш TukTuk — только Wi‑Fi к якорю.
- Якорь = один Android с батареей; для больших площадок — несколько якорей / ротация.
- Без HTTPS на LAN Safari может ругаться на «небезопасный» HTTP — это ожидаемо для локального hotspot.
