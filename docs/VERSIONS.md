# Версии TukTuk — хронология (не semver)

**Актуальная версия: `0.1.108`** (`versionName` в `app/build.gradle.kts`, тег `v0.1.108`).

## Важно

Числа вроде **`0.3.x` / `3.0` выглядят «выше» `0.1.N`, но по факту это более ранние релизы.**  
Не сравнивай их как обычный semver. Ориентир — дата тега / `versionCode` в APK / этот файл.

Линейка после закрытия V3 снова пошла как **`0.1.N`** (product rename), и с тех пор только она считается текущей.
