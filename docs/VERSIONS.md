# Версии TukTuk — хронология (не semver)

**Актуальная версия: `0.1.98`** (`versionName` в `app/build.gradle.kts`, тег `v0.1.98`).

## Важно

Числа вроде **`0.3.x` / `3.0` выглядят «выше» `0.1.96`, но по факту это более ранние релизы.**  
Не сравнивай их как обычный semver. Ориентир — дата тега / `versionCode` в APK / этот файл.

Линейка после закрытия V3 снова пошла как **`0.1.N`** (product rename), и с тех пор только она считается текущей.

## Как читать чужие упоминания

| Написал | Читать как |
|---------|------------|
| «V3 / v3.0» | этап разработки (август 2026), не «версия 3» поверх 0.1.96 |
| «APK v0.3.2» | промежуточный билд фаз V3, старше `0.1.4+` |
| «актуально 0.1.9» | устарело → **0.1.96** |
| GitHub sort by version | обманывает (`v3.0` выше `v0.1.96`) — смотри **Latest** / дату |
